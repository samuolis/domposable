# Domposable identity

The mark is a **D** containing two adaptable panes and a small accent dot. It is an original vector asset, scales to favicons and is included under the repository's Apache-2.0 license. Use the purple mark on a light background, with generous clear space.

![Domposable icon](assets/brand/icon.svg)

Assets: [icon SVG](assets/brand/icon.svg), [icon PNG](assets/brand/icon.png), [social card SVG](assets/brand/social.svg). The source SVGs remain editable. Repository topics and descriptive documentation help discovery; hashtags are for announcement text rather than API names.

Suggested announcement:

> Domposable: one Compose API for apps and semantic HTML. Shared Kotlin feature composables, adaptive layouts, replaceable design systems and application-owned state. Explore Android, iOS, desktop, DOM and Wasm demos.
>
> #Kotlin #KMP #CMP #ComposeMultiplatform #ComposeHTML #OpenSource

Use “Domposable”, singular, for the library. No claim that no competing library exists is needed; the practical distinction is the small portable feature API and semantic HTML renderer alongside Compose UI.
